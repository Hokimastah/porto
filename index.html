Selected work

Autonomous AI Data Analytics

Personal project, 2026

A local-first analytics agent. Give it a CSV, Excel or Parquet file and a goal. It profiles the data, proposes cleaning for you to approve, runs checked statistical analyses, and hands back an offline Plotly dashboard with an HTML report.

Bounded on purpose

Neither the language model nor the uploaded data can run arbitrary Python or SQL. Every analysis comes from an allowlist of 11 statistical operations, and every decision is written to an audit trail.

You approve the cleaning

The agent writes cleaning proposals and waits. Approved changes run in a fresh pass, the input hash has to match, and the original file is never overwritten.

Runs you can repeat

Step checkpoints let a stopped run resume, SQLite keeps the run history, and a watch mode re-runs the analysis when the source file changes.

How a run moves

  1. IngestLoads CSV, XLSX or Parquet from a sandboxed data folder.
  2. ProfileTags every column as a measure, dimension, date, identifier or sensitive field.
  3. Propose cleaningDuplicates, missing values and stray whitespace. Nothing changes until a person approves it.
  4. PlanDeterministic rules, or a local Ollama model choosing only from pre-validated steps.
  5. ExecuteAllowlisted operations, checkpointed after each step.
  6. Ground the findingsEvidence and alerts are computed, not generated. Any LLM narrative is labelled as a draft.
  7. ReportOffline Plotly dashboard and HTML report, indexed in SQLite.

Built with Python 3.11, Ollama, Plotly, Streamlit, SQLite, pytest

SAWIT-Net

Continual learning research, Apr – May 2026

Self-Adaptive Weighted Incremental Transfer Network

A PyTorch toolkit for teaching an image classifier new classes without wiping out the old ones. It trains in two stages, base classes first and new classes after, and holds back catastrophic forgetting with six complementary techniques.

Training objective

The classification loss plus four weighted terms that keep the old model’s knowledge in place.

  • ArcFace classification1.00
  • Embedding distillation0.30
  • Multi-scale feature distillation0.30
  • Contrastive distillation0.20
  • Prototype preservation0.15

A herding replay buffer adds the samples closest to each class centroid back into training.

Four modes for a fair comparison

ModeReplayDistillationPrototype loss
finetuneNoNoNo
replay_onlyYesNoNo
kd_onlyNoYesNo
fullYesYesYes

Every run reports accuracy, macro F1, macro recall and a forgetting score: base-class accuracy before the new session minus accuracy after it.

# install, then train base and incremental sessions in one call
pip install git+https://github.com/Hokimastah/SAWIT-Net.git
sawit-train --dataset-type csv --base base.csv --incremental new.csv --mode full

Built with PyTorch, ResNet-18 to ResNet-101 backbones, ArcFace, YAML configs. Ships as an installable package with a CLI and a Python API, MIT licensed.

Research

Blood flow abnormality detection on transcranial Doppler ultrasound

Academic research, Oct – Nov 2025. Published on IEEE Xplore.

A hybrid model for spotting abnormal blood flow in transcranial Doppler (TCD) signals. A ResNet extracts deep convolutional features and a support vector machine draws the decision boundary, pairing learned features with margin-based classification. CycleGAN reconstructs data and generates synthetic samples so the rarer class is not drowned out.

  1. TCD signals
  2. CycleGAN balancing
  3. ResNet features
  4. SVM classifier
